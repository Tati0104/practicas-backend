# Frontend — Prácticas Empresariales AVH

Aplicación React + Vite del sistema de gestión de prácticas empresariales.

## Inicio rápido

```powershell
copy .env.example .env
npm install
npm run dev
```

Abre **http://localhost:5173/login**
